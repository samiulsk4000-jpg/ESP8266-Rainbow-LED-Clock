# 🌈 ESP8266 Rainbow LED Digital Clock

**Developer:** Samiul SK

## Project Description
A WiFi-based digital LED clock using ESP8266, WS2812 LEDs, FastLED and NTP time synchronization.

## Hardware
- NodeMCU ESP8266
- 2 × WS2812 LED Rings (60 LEDs each)
- 5V Power Supply
- Connecting Wires

## Pin Configuration

| Component | ESP8266 Pin |
|---|---|
| LED Ring 1 | D5 |
| LED Ring 2 | D6 |
| Red LED | D7 |

## Features
- NTP WiFi Time Synchronization
- Rainbow Background
- Hour, Minute and Second Indicators
- FastLED Animation

## Installation
1. Install Arduino IDE.
2. Install FastLED library.
3. Install NTPClient library.
4. Select NodeMCU ESP8266 board.
5. Upload LED_Clock.ino.
